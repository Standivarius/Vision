## Product description and scope

The tested product is one foldable assembly comprising **three independently addressable IPS LCD panels**. It is different from the earlier DOXA configuration with HDMI inputs and a 65 W power supply. Data in this sheet applies only to the current 30 W USB-C / SM770 configuration.

### Interpretation of possible energy class

Using combined **DC** input power (21.4 W) and the aggregate panel active area gives an indicative **E** result (21 kWh per 1,000 hours).

**This is not a formal Great Britain energy-efficiency class declaration.** The charger is included with the product but its **AC input was not measured**, the product takes additional DC power from the host laptop, and the GOV.UK label generator expects a single diagonal and horizontal/vertical pixel count whereas this assembly contains **three** independently addressed panels. The prescribed method for the two feeds and the correct single-label screen geometry must be resolved before a compliant retail label can be issued.

A PDF generated by the GOV.UK label API is **not a certification** or government registration: the API simply renders supplier-provided values.
