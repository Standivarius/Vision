## Timing caveat

`Direct3D11CaptureFrame.SystemRelativeTime` remains treated as a compositor QPC timestamp. The signed differences between that timestamp and callback/render QPC are diagnostic only and are not interpreted as photon latency, end-to-end latency or frame age.

## Scenario coverage

The 20-second smoke started these phases:

1. `sync_flash`
2. `slow_motion`
3. `fast_motion` at the very end of the run

Because `fast_motion` began at approximately 20.0 seconds, the run did not meaningfully exercise all later scenario phases. This was a smoke test, not a full behavioral validation.

## Conclusion

This run materially changes Spike 1 status:

- physical Windows console execution is verified;
- two physical displays are enumerated by Visual;
- WGC monitor capture and D3D11 magnified presentation operate across the two-display physical topology;
- no Present failures occurred;
- no GPU-copy fallback was required;
- the user observed correct live Detail behavior.

This is strong evidence that WGC + D3D11 is viable enough to continue Spike 1 physical validation.

It is **not yet** a final latency/performance conclusion. Required next evidence includes a longer full-scenario run, recorded versus unrecorded comparison, repeated runs, soak/recovery behavior, and later four-display/Doxa hardware validation.
