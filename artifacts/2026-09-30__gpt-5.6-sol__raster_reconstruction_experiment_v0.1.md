## Human quality conclusion — 2026-09-30

The later human pass materially changes the interpretation of the engineering shortlist.

Observed owner judgements under the current physical two-screen setup:

- Vision baseline mode 0 at 2x in Microsoft Word was judged **"very good"**.
- Apparent pixelation in ChatGPT/browser at 2x was then observed to be visibly present in the source/main display itself at close range. This means the browser case does not demonstrate a generic Vision reconstruction defect: Vision necessarily magnifies source raster/subpixel structure that is already present.
- Vision baseline mode 0 at 4x in Microsoft Word was judged **better than ZoomText at 4x**.

Decision:

- retain mode 0 bilinear as the production/default raster baseline;
- keep modes 1/2/3 engineering-only;
- do not select Lanczos-2 or adaptive sharpen merely because edge metrics are higher;
- do not start semantic/xFont-style text rerendering from the current evidence;
- reopen raster work only for a reproducible, application-specific quality failure under matched conditions or materially new low-vision evidence.

This is a bounded conclusion, not a claim that bilinear is universally optimal across every application/display. It is the best-supported default for the current Vision product evidence.
