## Purpose

Record the first point at which the previously independent capture, coordinate, tracking and viewport spikes became one physically exercised `visual_app.exe` runtime.

## Integrated architecture now running

```text
Windows Graphics Capture source
  -> Windows POI evidence
       -> moving pointer
       -> UIA TextPattern2 caret
       -> UIA TextPattern insertion range
       -> Win32 caret fallback
       -> UIA focus
       -> Win32 focus fallback
  -> freshness + intent arbitration
  -> viewport controller
  -> locator model
  -> D3D11 crop / scale / locator
  -> non-activating second-screen Detail window
```

UI Automation runs on a separate worker thread. The D3D11 renderer is provider-agnostic and receives only viewport/locator state.
