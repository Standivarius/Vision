# Vision UI / DPI / AltGr / localisation audit v0.1

Date: 2026-09-30
GitHub: #20
Status: AUDIT COMPLETE / IMPLEMENTATION NEXT

## Observed repository facts

- The application and diagnostics explicitly request Per-Monitor V2 DPI awareness.
- Settings and Help use fixed initial dimensions and hard-coded pixel layouts.
- Settings/Help/Hint have no WM_DPICHANGED handling and no GetDpiForWindow-based layout/font scaling.
- Settings uses caption-text lookup with FindWindowExW for several layout targets. This is fragile under localisation and duplicate captions.
- User-visible Settings, Help, menu, hint and error strings are hard-coded directly in C++ rather than behind stable resource/string keys.
- Persistent settings/diagnostic identifiers are already language-neutral enough to remain separate from display strings.
- Global hotkeys use MOD_CONTROL | MOD_ALT | MOD_NOREPEAT for 0/1/2/3/4/Q/S/T/H.

## Deterministic AltGr collision probe

The current Windows installation only has en-US configured, so a manual machine test would not qualify AltGr behaviour. A disposable thread-local probe loaded installed Windows keyboard-layout DLLs and used VkKeyScanEx to identify characters produced by Ctrl+Alt (AltGr) on Vision hotkey keys. It made no permanent keyboard-layout change.

Romanian (Programmers), KLID 00020418, collisions include:

- AltGr+Q -> â
- AltGr+S -> ș
- AltGr+T -> ț
- AltGr+0/1/2/3/4 -> dead/diacritic characters

German, KLID 00000407, collisions include:

- AltGr+Q -> @
- AltGr+0 -> }
- AltGr+2 -> ²
- AltGr+3 -> ³

Conclusion: the current global Ctrl+Alt shortcut family is not localisation-safe. This is a concrete product defect, not merely a theoretical concern.

## Recommended implementation order

1. Remove caption-based layout lookup by storing control HWNDs/IDs directly.
2. Add DPI-aware layout primitives and WM_DPICHANGED handling to Settings and Help; recreate fonts at current window DPI.
3. Introduce a small stable user-visible string catalogue/resource seam without translating yet.
4. Replace the default global Ctrl+Alt shortcut family with a localisation-safe command scheme after a bounded Windows/conflict review; retain commands independently of physical key bindings so shortcuts can later be configurable.
5. Add deterministic tests/diagnostics for command bindings and resource keys.
6. Run UI surface smoke at multiple DPI/text-scale conditions and rerun canonical regression.

## Boundary

Do not rename compatibility identifiers such as visual_app.exe, Standivarius.Visual, Visual settings paths or VISUAL_* environment/registry contracts as part of localisation work.
