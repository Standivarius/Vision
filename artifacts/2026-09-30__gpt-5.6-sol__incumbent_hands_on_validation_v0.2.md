# Vision incumbent hands-on validation v0.2

**Date:** 2026-09-30  
**Status:** pre-Opus hands-on evidence substantially complete  
**Scope:** ZoomText 2026, SuperNova Magnifier 25.05, Vision control baseline on the same Dell two-monitor bench.

## 1. Method

Black-box comparison on Marius-DELL using the same local HTML fixture and deterministic stimulus harness. No decompilation, binary inspection, licence bypass or proprietary implementation inference.

Controlled workloads:

- pointer sweep;
- caret navigation;
- keyboard-focus navigation;
- cross-monitor pointer movement;
- selected zoom / temporary-1x behaviour;
- representative visual-enhancement presets;
- live product/menu inventory.

Evidence includes timestamped stimuli, Windows pointer/caret/foreground state, process resource samples, full-desktop recordings/stills and product-presence checks.

## 2. ZoomText 2026

Official Freedom Scientific build `2026.2606.73.400` was installed and its signature verified. Windows required restart; pre-reboot evidence was discarded. Canonical runs were performed after restart in the documented 40-minute unlicensed mode.

Observed hands-on:

- stable pointer, caret and focus tracking runs;
- global zoom hotkeys;
- temporary 1x and return;
- post-install restart requirement;
- multi-monitor operation remained active during the cross-monitor run, although one wrapper timeout prevented treating that particular video as canonical qualitative evidence.

Current Freedom Scientific material independently confirms cursor, focus and pointer enhancements, Freeze View, configurations, three-display support and multiple-monitor boundary controls.

## 3. SuperNova Magnifier 25.05

Official Dolphin Magnifier 25.05 network/trial package was downloaded from Dolphin, signature-verified and installed. The real package was the downloaded `SnovaMag.msi`; Dolphin EasyReader and Remote Support were also installed as package components.

Canonical SuperNova runs completed for:

- pointer sweep;
- caret navigation;
- focus navigation;
- cross-monitor movement.

One caret run initially failed because the fixture textarea AutomationId was not visible through UI Automation while SuperNova was active. The harness was hardened to fall back to deterministic foreground/keyboard interaction and to record the fallback. A later focus run exposed UIA normally. This is evidence of intermittent accessibility-surface interaction, not yet evidence of a SuperNova defect.

Representative visual enhancement testing included live selection of `Large Red` and `Large Yellow` highlighting schemes and capture of the resulting focus/caret behaviour.

The live SuperNova menu/control panel was also enumerated, confirming the magnifier-only edition exposes eight view modes, extensive colour schemes, highlighting presets, mouse-pointer settings, Hooked Areas, Doc Reader settings, multiple-monitor settings, application/situation configurations, touchscreen settings and other ancillary features.

## 4. Resource observations

These short-run process numbers are implementation observations only; they are not quality rankings and should not be extrapolated to battery life or whole-system cost.

- Vision `visual_app.exe` stayed around **52 MB working set** in matched pointer/focus control runs.
- SuperNova `Lunar.exe` was roughly **76-120 MB max working set** across the completed short scenarios, with state-dependent private memory around 198-270 MB.
- ZoomText `Zt.exe` was much more variable in the captured runs: roughly **170-570 MB working set**, with some runs near 570 MB and private memory around 445 MB.

The products use very different architectures and background components, so this is useful for feasibility/performance context, not a purchasing judgment.
