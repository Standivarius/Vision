### Pointer-visibility run

`lab/benchmarks/visual_regression/runs/2026-09-24_08-03-26__pointer_visibility/`

Evidence:

- 30 fps, 3840x1080 video;
- 1,080 Visual telemetry frames;
- 561 cursor-ground-truth samples;
- zero Present failures;
- telemetry says pointer selection is healthy during fast movement and locator_visible remains true.

However, this first harness was **not PMv2-aware before display enumeration**. The 150%-scaled primary was seen as 1280x720 logical while the real screen is 1920x1080. Therefore spatial pixel conclusions from this run are provisional.

### Pointer-crossing run
