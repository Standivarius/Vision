# Vision display lifecycle census - non-disruptive phase v0.1

Date: 2026-09-30

## Result
A pure TopologyReconciler state machine and synthetic event census now define the initial in-process recovery contract without physically disturbing the owner's displays.

Rules proven by unit tests:
- any topology-change signal immediately puts reconciliation into Debouncing;
- while Debouncing, old topology generations are not accepted for movement decisions;
- each additional event restarts the quiet window;
- initial quiet/debounce window: 500 ms;
- after 500 ms without a later event, state becomes RebuildReady;
- no topology generation is accepted until rebuild completion;
- rebuild completion installs the new generation and returns Stable;
- old generations remain rejected.

CTest is 17/17 PASS after adding topology_reconciler_tests.

## Physical event census status
Not executed yet: HDMI/DP unplug/reconnect, monitor sleep/wake, resolution mutation, scaling mutation, primary-display mutation, lock/unlock. These are deliberately deferred because the owner requested uninterrupted autonomous development and they can disturb the active Dell session.

The current production reaction to WM_DISPLAYCHANGE is confirmed in live code: set DisplayTopologyChanged shutdown reason and destroy the detail window. Slice 7 must replace that exit path with whole-workspace rebuild.

## Guidance
Use whole-workspace rebuild initially, not piecemeal repair:
1. signal topology change;
2. invalidate current generation for movement;
3. debounce 500 ms;
4. enumerate new topology;
5. resolve saved WorkspaceIntent against new topology without mutating intent;
6. stop old CaptureRunner;
7. destroy/recreate capture/output/renderer/window bindings as one workspace runtime;
8. install new topology generation;
9. resume evidence/movement only after rebuild completes.

Physical event timing may later tune 500 ms; it is not yet claimed as empirically optimal.
