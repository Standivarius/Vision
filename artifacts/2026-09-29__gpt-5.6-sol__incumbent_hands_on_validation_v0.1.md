# Vision incumbent hands-on validation v0.1

**Date:** 2026-09-29
**Status:** in progress; ZoomText hands-on complete enough for architecture input, SuperNova pending installation

## Method

Black-box comparison on Marius-DELL using the same two-screen fixture and deterministic stimulus harness already validated against Vision. No decompilation, binary inspection, licence bypass or proprietary implementation inference.

Controlled workloads:

- pointer sweep;
- caret navigation;
- keyboard-focus navigation;
- cross-monitor pointer movement;
- zoom-step changes;
- temporary 1x / exact-return behaviour.

Evidence includes full-desktop recording/stills, timestamped stimulus events, Windows cursor/caret/foreground state, process resource samples and product-presence checks.

## ZoomText 2026

Installed official Freedom Scientific build `2026.2606.73.400`; Authenticode signature verified before install. Windows reported a restart required, so pre-reboot evidence was discarded. Canonical testing was performed only after reboot and after selecting ZoomText's documented `Continue to Run in 40 Minute Mode` option.

The product remained active through the canonical pointer, caret and focus tests and responded to the documented global zoom and temporary-1x hotkeys. A cross-monitor run also retained an active ZoomText process; its raw video was not finalised correctly when the outer harness timed out, so that video is not treated as canonical qualitative evidence.
